<h1>Music Streaming Backend</h1>

<p>A Microservices-based application about Music Streaming as Spotify. The purpose of this application is to learn and gain knowledge of Microservice architecture using Java springboot. With a Song Service and User Service communicate with each other through  Eureka service registry a long with the service management by API Gateway</p>
